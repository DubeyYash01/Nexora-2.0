SUPABASE SETUP
═══════════════════════════════════════

Create these tables in Supabase:

TABLE: profiles
  id              uuid (references auth.users, primary key)
  email           text
  full_name       text
  role            text  (values: 'student' | 'maker' | 'professor' | 'professional')
  college_name    text  (nullable)
  course          text  (nullable)
  avatar_url      text  (nullable)
  created_at      timestamp with time zone (default now())
  updated_at      timestamp with time zone (default now())

TABLE: projects
  id              uuid (default gen_random_uuid(), primary key)
  user_id         uuid (references profiles.id)
  title           text
  description     text
  idea_input      text  (original idea the user typed)
  status          text  (values: 'draft' | 'in_progress' | 'completed')
  current_step    integer (default 0)
  ai_analysis     jsonb  (stores full AI analysis result)
  components      jsonb  (stores component list)
  build_plan      jsonb  (stores all steps)
  created_at      timestamp with time zone
  updated_at      timestamp with time zone

TABLE: project_members
  id              uuid (default gen_random_uuid(), primary key)
  project_id      uuid (references projects.id)
  user_id         uuid (references profiles.id)
  role            text  (values: 'owner' | 'collaborator')
  joined_at       timestamp with time zone

Enable Row Level Security on all tables.
Profiles: users can read/update their own profile.
Projects: users can CRUD their own projects, 
          collaborators can read projects they are members of.

═══════════════════════════════════════
AUTHENTICATION SYSTEM
═══════════════════════════════════════

Use Supabase Auth (email + password).

Flow:
1. User signs up with email + password + full name
2. Supabase creates auth user
3. Trigger automatically creates a row in profiles table
4. User is redirected to /role-select
5. User picks their role (student / maker / professor / professional)
6. Role is saved to profiles table
7. User is redirected to /dashboard

Create a Supabase database trigger:
  After insert on auth.users →
  Automatically insert into profiles(id, email) 
  using the new user's id and email.

AuthContext.jsx must provide:
  - user (supabase auth user object)
  - profile (row from profiles table)
  - loading (boolean)
  - signUp(email, password, fullName)
  - signIn(email, password)
  - signOut()
  - updateProfile(data)

Protected routes: /dashboard and all inner pages 
require authentication. Redirect to /login if not authenticated.
